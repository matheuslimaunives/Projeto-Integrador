# Conecta Vida IA

Protótipo inicial da plataforma Conecta Vida IA.

## Público inicial
- Pessoas com dificuldade de fala
- Pessoas idosas

## Requisitos implementados
- RF01 — cadastro do usuário
- RF02 — seleção de recursos de acessibilidade
- RF03 — adaptação da tela inicial conforme os recursos escolhidos

## Requisitos não funcionais considerados
Simplicidade, acessibilidade, facilidade de aprendizado, privacidade, segurança, desempenho, compatibilidade e personalização.

## Tecnologias
HTML5, CSS3 e JavaScript, sem dependências externas. A escolha facilita a primeira validação e a publicação no GitHub Pages.

## Execução
Abra `index.html` no navegador.

## Evolução
Esta é a primeira camada. Voz, câmera, Libras com reconhecimento automático e integrações de IA serão desenvolvidas posteriormente, depois da validação da interface e dos fluxos básicos.
